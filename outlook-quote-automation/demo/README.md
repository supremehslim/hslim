# 테스트 영상 · 60초

[test-demo.mp4 영상 보기·다운로드](test-demo.mp4)

![생성 견적서 저장값 미리보기](poster.png)

- 실제 실행한 자동 테스트 6개의 로그와 생성된 XLSX/HTML 파일 내용을 시각화한 자막 영상입니다(음성 없음).
- **화면 녹화가 아니며, 실제 Outlook 계정이나 실시간 Google 가격 검색에 연결한 영상이 아닙니다.** 모의 응답을 사용한 기능 검증입니다.
- 00:00 처리 흐름과 검증 범위
- 00:06 실제 테스트 로그 재생
- 00:22 실제 데모 명령 실행 결과
- 00:30 생성 XLSX 저장값 확인
- 00:43 생성 HTML 메일 내용 미리보기
- 00:54 결과와 실제 연결에 필요한 설정

함께 제공: `test-run.txt` 실행 로그, `데모_견적서.xlsx`, `데모_메일.html`. 데모 단가와 고객 주소는 가상 테스트값입니다.

실제 M365 임시보관함 저장과 실시간 가격 검색은 M365 로그인, SerpApi 키, 검색 가격 VAT 기준 설정 후 Windows PC에서 별도로 확인해야 합니다.
