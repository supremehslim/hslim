# 모아 · CSV 파일 합치기

브라우저에서 CSV 파일을 이어 붙이고 UTF-8 BOM CSV로 다운로드하는 정적 웹페이지입니다. 파일 데이터는 서버로 전송하지 않습니다. 첨부한 이름·점수 CSV 4개는 `samples/`에 포함되어 있습니다.

## 실행

```sh
cd /workspace/hslim/csv-merger
npm start
```

포트 3000에서 실행됩니다. 별도 패키지 설치나 API 키가 필요하지 않습니다. Python 3과 Node.js가 있는 환경을 사용하세요. 검증은 `npm test`로 실행합니다.

파일 선택 또는 드래그 앤 드롭 → 파일 합치기 → CSV 다운로드. 파일명 기준으로 정렬하며 열 이름과 순서가 같은 파일만 합칩니다. 중복 행은 유지합니다. UTF-8 및 한국어 CP949/EUC-KR 파일을 지원하며 미리보기에는 처음 10행을 표시합니다.
